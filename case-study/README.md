# Case-study images

All images use the viratmohan.com look: cream paper `#f4ead4`, ink `#1a1410`, gold rule `#d4af37`, terracotta accent `#d9714b`, Anton headlines, Instrument Serif subheads, Inter body. Tokens mirror `src/styles/global.css` and live in `brand.py`. Fonts in `fonts/` are from @fontsource (SIL OFL).

New image: import `frame` and `clean` from `brand.py`, then run `python3 <name>.py` (needs matplotlib).
